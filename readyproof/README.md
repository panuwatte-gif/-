# ReadyProof — แคปหลักฐานออเดอร์ Grab อัตโนมัติ (Android)

แอปเสริมสำหรับมือถือเครื่องที่เปิด **GrabMerchant** ทำหน้าที่แทนคนที่ต้องคอยแคปหน้าจอ:

| จังหวะ | แอปทำอะไร | ชื่อไฟล์ |
|---|---|---|
| กดปุ่ม **"พร้อมจัดส่ง"** | แคปทันที + จดเลข GF ของการ์ดที่กด + เวลาที่เหลือ (เช่น "เหลือ 5:53") | `GF-613_PRESS_2026-09-28_10-58-02.jpg` |
| เห็นออเดอร์ **"กำลังค้นหาคนขับ..." / "คนขับจะมารับใน..."** | แคป 1 ครั้งต่อออเดอร์ (ภาพ READY แบบที่ร้านใช้อยู่) | `GF-613_READY_...jpg` |
| เลื่อนหน้า **ประวัติ** แล้วเจอ **"ล่าช้าไป X นาที"** | แคป + จดว่าออเดอร์ไหนล่าช้ากี่นาที | `GF-450_DELAY-10m_GF-697_DELAY-6m_...jpg` |

สิ้นวันเปิดหน้า **รายงาน** → แอปจับคู่ "ออเดอร์ที่ Grab บอกว่าล่าช้า" กับ "ภาพกดพร้อมจัดส่ง/READY ของเลข GF เดียวกัน" ให้เอง
(✅ มีหลักฐาน / ❌ ไม่มีหลักฐาน + % ล่าช้าจริง) แล้วกดส่งภาพทั้งชุดเข้า Google Drive / LINE ได้ในครั้งเดียว — ไม่ต้องให้ AI จับคู่อีก

- **ไม่ยุ่งกับระบบ Grab**: แค่อ่านหน้าจอ (แบบเดียวกับโปรแกรมอ่านหน้าจอสำหรับผู้พิการ) ไม่กดอะไรแทน ไม่ส่งอะไรเข้าเซิร์ฟเวอร์ Grab
- **ไม่มีสิทธิ์อินเทอร์เน็ต**: ข้อมูลและภาพอยู่ในเครื่องเท่านั้น ออกจากเครื่องเมื่อคุณกดส่งเองเท่านั้น
- ภาพอยู่ในแกลเลอรี อัลบั้ม **ReadyProof** (Pictures/ReadyProof)

## ติดตั้งครั้งแรก (~10 นาที, ทำครั้งเดียว)

ต้องเป็น **Android 11 ขึ้นไป** และเป็นเครื่องเดียวกับที่ใช้แอป GrabMerchant

1. **ปิด Play Protect ชั่วคราว** — ในไทย Google บล็อกการติดตั้งแอปนอก Play Store ที่ขอสิทธิ์ "การช่วยเหลือพิเศษ" (ถ้าไม่ปิดจะขึ้นว่า *ถูกบล็อกเพื่อปกป้องอุปกรณ์* และไม่มีปุ่มให้ติดตั้งต่อ)
   Play Store → แตะรูปโปรไฟล์มุมขวาบน → Play Protect → ⚙️ → ปิด "สแกนแอปด้วย Play Protect"
   *Samsung รุ่นใหม่*: ปิด **Auto Blocker** ชั่วคราวด้วย (ตั้งค่า → ความปลอดภัยและความเป็นส่วนตัว → Auto Blocker)
2. เปิดลิงก์ดาวน์โหลดด้วย **Chrome** → ดาวน์โหลด → แตะไฟล์ → ถ้าถาม "อนุญาตให้ติดตั้งแอปที่ไม่รู้จัก" → อนุญาต → **ติดตั้ง**
3. **เปิด Play Protect / Auto Blocker กลับ** เหมือนเดิม (ถ้า Play Protect ถามเรื่อง ReadyProof ให้เลือกเก็บแอปไว้)
4. เปิดแอป **ReadyProof** → หน้าแรกจะบอกทีละขั้น:
   - กด **"เปิดหน้าการช่วยเหลือพิเศษ"** → ReadyProof (อาจอยู่ในหัวข้อ "แอปที่ดาวน์โหลด") → เปิดสวิตช์ → อนุญาต
   - ถ้าสวิตช์เป็นสีเทา / ขึ้นว่า **"การตั้งค่าที่ถูกจำกัด"** → กด "เปิดหน้าข้อมูลแอป" → แตะ **⋮** มุมขวาบน → **"อนุญาตการตั้งค่าที่ถูกจำกัด"** → กลับไปเปิดสวิตช์อีกครั้ง
5. กด **"อนุญาตให้ทำงานเบื้องหลังตลอด"** (กันมือถือปิดแอปเอง)
6. **ทดสอบ**: กด "ทดสอบ: แคปหน้าจอใน 5 วินาที" → แอป Grab จะเปิดขึ้น → รอข้อความ 📸 → กลับมาดูใน "ภาพที่แคปไว้"
7. ทดสอบจริง: กด "พร้อมจัดส่ง" ออเดอร์ถัดไปตามปกติ ต้องมีข้อความเด้ง **"📸 GF-xxx กดพร้อมจัดส่ง"**

> ถ้าติดตั้งไม่ได้เลยแม้ปิด Play Protect แล้ว ดูหัวข้อ "แผนสำรองการติดตั้ง" ด้านล่าง

## อัปเดตเวอร์ชันใหม่

ดาวน์โหลดจากลิงก์เดิม → ติดตั้ง**ทับ**ได้เลย ไม่ต้องลบของเดิม (การตั้งค่า / ภาพ / สิทธิ์การช่วยเหลือพิเศษ อยู่ครบ)
ถ้าติดตั้งทับแล้ว Play Protect บล็อก ให้ปิด Play Protect ชั่วคราวแบบข้อ 1

## ใช้งานประจำวัน

- ใช้ Grab ตามปกติ กด "พร้อมจัดส่ง" เหมือนเดิม — เห็นข้อความเด้ง 📸 = เก็บหลักฐานแล้ว
- **แนะนำ**: หลังกดพร้อมจัดส่ง ให้แตะแท็บ **"พร้อมจัดส่ง"** สักครั้ง จะได้ภาพ READY ที่มีคำว่า "กำลังค้นหาคนขับ..." ซึ่งเป็นหลักฐานที่ชัดที่สุด (แตะทีเดียวได้ทุกออเดอร์ในแท็บ ไม่ต้องแคปเอง)
- ไม่มีข้อความเด้ง = แอปไม่ได้เก็บ → แตะปุ่มลอย (ด้านล่าง) หรือแคปหน้าจอเองแบบเดิมไปก่อน

## สิ้นวัน

1. Grab → คำสั่งซื้อ → **ประวัติ** → เลื่อนดูออเดอร์ของวันนี้**ให้ครบ** (เลื่อนช้าๆ) — แอปอ่าน "ล่าช้าไป X นาที" เอง
2. ReadyProof → **รายงานออเดอร์ล่าช้า** → ดู ✅ / ❌ และ % ล่าช้าจริง
3. **ส่งภาพหลักฐาน** → เลือก Drive → เลือกโฟลเดอร์ (เช่น ตรวจความล่าช้าแล้ว/จับคู่แล้ว/28Sep) → อัปโหลดทั้งชุด
4. **คัดลอกสรุป** → วางใน LINE ถึง Grab หรือในตาราง · **ส่งออก CSV** → เปิดด้วย Google Sheets

> หน้าประวัติของ Grab แสดงแค่ "เวลา" ไม่มีวันที่ → ควรเลื่อนดูภายในวันเดียวกัน หรืออย่างช้าก่อนเปิดร้านวันถัดไป

## ปุ่มลอยสำหรับแคปเอง (ไม่บังคับ)

ตั้งค่ามือถือ → การช่วยเหลือพิเศษ → ReadyProof → เปิด **"ทางลัด ReadyProof"** → เลือก "แตะปุ่มการช่วยเหลือพิเศษ"
จะมีปุ่มเล็กลอยบนจอ แตะ = แคปทันทีพร้อมจดเลข GF ที่เห็นบนจอ

## ถ้าระบบหยุดทำงานเอง (หน้าแรกขึ้นสีเหลือง/แดง)

- ทุกยี่ห้อ: กด "อนุญาตให้ทำงานเบื้องหลังตลอด" · อย่าปัดปิด ReadyProof ทิ้งจากหน้าแอปล่าสุด
- Samsung: ตั้งค่า → แบตเตอรี่ → ขีดจำกัดการใช้งานพื้นหลัง → แอปที่ไม่เข้าสู่โหมดสลีปเลย → เพิ่ม ReadyProof
- Xiaomi/Redmi/POCO: ตั้งค่า → แอป → ReadyProof → เปิด "เริ่มอัตโนมัติ" + ตัวประหยัดแบตเตอรี่ "ไม่มีข้อจำกัด"
- OPPO/realme/vivo: ตั้งค่า → แบตเตอรี่ → ReadyProof → อนุญาตทำงานเบื้องหลัง + เริ่มอัตโนมัติ

## ถ้า Grab เปลี่ยนหน้าตาแอป

- กดพร้อมจัดส่งแล้วไม่มีข้อความเด้ง → ReadyProof → ตั้งค่า → "ปุ่มที่เพิ่งกดในแอป Grab" → แตะ **"ใช้ปุ่มนี้"** ที่ปุ่มที่เพิ่งกด → บันทึก
- ยังไม่ได้ → ตั้งค่า → เปิด "เก็บข้อมูลหน้าจอเพื่อแก้ปัญหา" → ใช้ Grab ให้ผ่านแท็บ กำลังเตรียม / พร้อมจัดส่ง / ประวัติ → "ส่งออกไฟล์ช่วยแก้ปัญหา" แล้วส่งไฟล์นั้นมาให้แก้

## แผนสำรองการติดตั้ง (ถ้า Google บล็อกแม้ปิด Play Protect)

Google เริ่มระบบ "ยืนยันตัวตนผู้พัฒนา" ในไทยตั้งแต่ **30 ก.ย. 2026** — ตามเอกสารของ Google รอบนี้บังคับเฉพาะแอปจาก Store ที่ร่วมโครงการ ส่วนแอปที่ติดตั้งจากไฟล์โดยตรงยังไม่ถูกบังคับจนถึงรอบทั่วโลกปี 2027
ถ้าเครื่องไหนบล็อก เลือกทางใดทางหนึ่ง:

1. **Advanced flow (ทำครั้งเดียวต่อเครื่อง)**: เปิดโหมดนักพัฒนา → ตัวเลือกสำหรับนักพัฒนา → "แอปจากนักพัฒนาที่ยังไม่ยืนยัน" → เปิด → รีสตาร์ท → **รอ 24 ชม.** → ยืนยันด้วยลายนิ้วมือ/PIN → ติดตั้งได้ตามปกติ
2. **บัญชี Limited distribution (ฟรี, ไม่เกิน 20 เครื่อง, ไม่ต้องใช้บัตรประชาชน)**: ใช้บัญชี Google ที่เปิดการยืนยัน 2 ขั้นตอน + มีโปรไฟล์การชำระเงิน Google → สมัคร Android Developer Console → ลงทะเบียนแอป `io.github.panuwattegif.readyproof` พร้อม SHA-256 ของกุญแจเซ็นแอป (ใน `keystore/README.md`) → เพิ่มมือถือร้านด้วย QR code
3. **ADB จากคอมพิวเตอร์** (ไม่ต้องยืนยันใดๆ): `adb install -r ReadyProof.apk`

## ความเสี่ยงที่ควรรู้

- **บัญชี Grab**: แอปนี้แค่อ่านหน้าจอและแคปภาพ เหมือนคนแคปเอง ไม่แตะเซิร์ฟเวอร์ Grab — โอกาสมีปัญหาต่ำมาก แต่ไม่ใช่ศูนย์ (บางแอปตรวจเจอแอป "การช่วยเหลือพิเศษ" ได้) ถ้าวันหนึ่ง Grab แจ้งเตือนเรื่องนี้ ให้ปิดสวิตช์ ReadyProof ในหน้าการช่วยเหลือพิเศษได้ทันที
- **ภาพหลักฐาน**: เป็นภาพหน้าจอดิบ ไม่มีการแต่งเติม เวลาดูจากนาฬิกาบนแถบสถานะเหมือนภาพที่แคปเอง
- **ความจุ**: ประมาณ 30–50 MB/วัน ลบอัตโนมัติเมื่อเกิน 30 วัน (เปลี่ยนได้ในตั้งค่า)

## สำหรับผู้พัฒนา

```
readyproof/
  core/   Kotlin ล้วน ไม่พึ่ง Android — อ่านการ์ดออเดอร์, กฎ READY/ล่าช้า, จับคู่รายงาน, ชื่อไฟล์, JSON (มี unit test)
  app/    Android: ProofService (accessibility), CaptureManager (แคปเงียบ + MediaStore), หน้าจอ ui/*
```

- ทุกพฤติกรรมอยู่ใน `core/.../Config.kt` (คำบนปุ่ม, คำสถานะ, รูปแบบเลข GF, แอปเป้าหมาย) แก้ได้จากหน้าตั้งค่าในแอป
- โค้ดอ่านหน้าจอทดสอบกับโครงหน้าจอจริงของ GrabMerchant (แท็บ กำลังเตรียม / พร้อมจัดส่ง / ประวัติ) ใน `core/src/test/.../Trees.kt`
- Build: GitHub Actions (`.github/workflows/readyproof-android.yml`) รัน unit test → สร้าง APK → เผยแพร่ที่ release `readyproof-latest`
- ทดสอบเฉพาะส่วน logic: `cd readyproof && ./gradlew :core:test`
