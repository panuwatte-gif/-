# ReadyProof — แคปหลักฐานแท็บ Ready ของ Grab อัตโนมัติ (Android)

> การตั้งค่า Google Drive, การผูกร้าน, ไฟล์รายงาน/manifest และข้อจำกัดเชิงเทคนิค: ดู [END_TO_END.md](END_TO_END.md)

แอปสำหรับ **มือถือ 1 เครื่องที่เปิด GrabMerchant ค้างไว้ที่แท็บ Ready (พร้อมจัดส่ง)** — เครื่องนี้ไม่ได้ใช้รับออเดอร์ มีหน้าที่เก็บหลักฐานอย่างเดียว (ใช้ได้ทั้งแอป Grab ภาษาไทยและอังกฤษ)

| เวลา | แอปทำอะไรเอง |
|---|---|
| ทั้งวัน | ออเดอร์ใหม่เข้าแท็บ Ready → แคปทันที **ออเดอร์ละ 1 ภาพ** (ออเดอร์เดิมที่ยังรอไรเดอร์ไม่แคปซ้ำ แต่ออเดอร์ใหม่แคปเสมอแม้ของเก่ายังอยู่) |
| รายการยาวเกินจอ | **เลื่อนลงเอง** ไล่แคปทุกออเดอร์ แล้วจอดไว้ท้ายรายการ (ออเดอร์ใหม่ต่อท้าย) |
| ทุกภาพ | ต้องเห็น **เลข GF + สถานะเต็มๆ** ไม่โดนขอบจอหรือปุ่มลอยบัง ถ้าโดนตัด เลื่อนให้เห็นเต็มก่อน แล้ว**ตรวจซ้ำหลังแคป**ว่าจอไม่ขยับ ถ้าขยับทิ้งภาพแล้วแคปใหม่ — ไม่มี "แคปวืด" |
| Grab เด้งไปแท็บอื่น | พากลับแท็บ Ready เอง (ถ้ามีคนใช้เครื่องอยู่ รอให้ว่าง 2 นาที) |
| 19:05 (ปิดร้าน 19:00 + เผื่อ 5 นาที) | ดูแท็บ Ready และกำลังเตรียม ถ้ายังมีออเดอร์ค้าง รอแล้วดูใหม่ทุก 5 นาทีจนว่าง → เปิดแท็บ **ประวัติ** อ่านยอด **Completed / Cancelled** → เลื่อนอ่านทุกออเดอร์ แคปทุกรายการที่ **Delayed by** → จับคู่ → แจ้งเตือน "สรุปสิ้นวันพร้อมแล้ว" |

**รายงานสิ้นวัน** แยก 3 กลุ่ม:

- ✅ **หลักฐานว่าร้านกดทัน** — ภาพแรกในแท็บ Ready แสดง "คนขับจะมารับใน X นาที" / "กำลังค้นหาคนขับ" (คนขับยังไม่มา)
- ⚠️ **หลักฐานว่าร้านช้าจริง** — ภาพแรกแสดง "คนขับของคุณมาถึงแล้ว" หรือการ์ดชมพู "โปรดเตรียมคำสั่งซื้อนี้ให้พร้อมจัดส่ง"
- ❓ **ไม่มีหลักฐาน / ระบบจับไม่ได้** — ไม่ได้แปลว่าช้าจริง

พร้อมตัวเลข: ยอด Completed ของ Grab เทียบกับจำนวนที่แอปอ่านได้ (ต้องเท่ากัน), ออเดอร์ที่มีภาพ Ready กี่รายการ,
**% ล่าช้าแบบ Grab** = ล่าช้าทั้งหมด ÷ Completed และ **% ที่ร้านควรได้** = (ล่าช้าทั้งหมด − กดทัน) ÷ Completed

หลักฐานเป็นชุด ออเดอร์ละ 2 ไฟล์แบบที่ร้านทำอยู่: `GF-613_READY.jpg` + `GF-613_DELAY.jpg` — ถ้าผูกร้านและเชื่อม Google Drive ไว้ (หน้า **ร้าน / Google Drive / คิวส่งไฟล์**) แอปส่งภาพ + สรุป + manifest เข้าโฟลเดอร์ "ออเดอร์รอตรวจ" ของร้านนั้นเองหลังปิดร้าน (กะเพรา / ลูกสาวทำเอง) ไม่ได้เชื่อมก็กดแชร์เองได้เสมอ

- **สิ่งที่แอปทำในแอป Grab มีแค่**: เลื่อนรายการ, แตะแท็บ (Ready / กำลังเตรียม / ประวัติ) หรือเมนู "คำสั่งซื้อ" ที่แถบล่าง, กดย้อนกลับเมื่อหลุดไปหน้ารายละเอียด — **ไม่แตะการ์ดออเดอร์หรือปุ่มใดๆ ของออเดอร์** ไม่ใช้ API ลับของ Grab
- **เก็บในเครื่องก่อน**: Drive เป็นส่วนเสริมเบื้องหลัง ถ้าเน็ต/บัญชีมีปัญหา การแคปและรายงานยังทำงานปกติ
- ภาพดิบอยู่ในแกลเลอรี อัลบั้ม **ReadyProof** (Pictures/ReadyProof) แอปไม่ลบภาพเอง

## ติดตั้งครั้งแรก (~10 นาที, ทำครั้งเดียว)

ต้องเป็น **Android 11 ขึ้นไป** ติดตั้งบนเครื่องที่ล็อกอิน GrabMerchant ไว้ (เครื่องที่จะวางเปิดแท็บ Ready ทิ้งไว้)

1. **ปิด Play Protect ชั่วคราว** — ในไทย Google บล็อกการติดตั้งแอปนอก Play Store ที่ขอสิทธิ์ "การช่วยเหลือพิเศษ" (ถ้าไม่ปิดจะขึ้นว่า *ถูกบล็อกเพื่อปกป้องอุปกรณ์* และไม่มีปุ่มให้ติดตั้งต่อ)
   Play Store → แตะรูปโปรไฟล์มุมขวาบน → Play Protect → ⚙️ → ปิด "สแกนแอปด้วย Play Protect"
   *Samsung รุ่นใหม่*: ปิด **Auto Blocker** ชั่วคราวด้วย (ตั้งค่า → ความปลอดภัยและความเป็นส่วนตัว → Auto Blocker)
2. เปิดลิงก์ดาวน์โหลดด้วย **Chrome** → ดาวน์โหลด → แตะไฟล์ → ถ้าถาม "อนุญาตให้ติดตั้งแอปที่ไม่รู้จัก" → อนุญาต → **ติดตั้ง**
3. **เปิด Play Protect / Auto Blocker กลับ** เหมือนเดิม (ถ้า Play Protect ถามเรื่อง ReadyProof ให้เลือกเก็บแอปไว้)
4. เปิดแอป **ReadyProof** → หน้าแรกจะบอกทีละขั้น:
   - กด **"เปิดหน้าการช่วยเหลือพิเศษ"** → ReadyProof (อาจอยู่ในหัวข้อ "แอปที่ดาวน์โหลด") → เปิดสวิตช์ → อนุญาต
   - ถ้าสวิตช์เป็นสีเทา / ขึ้นว่า **"การตั้งค่าที่ถูกจำกัด"** → กด "เปิดหน้าข้อมูลแอป" → แตะ **⋮** มุมขวาบน → **"อนุญาตการตั้งค่าที่ถูกจำกัด"** → กลับไปเปิดสวิตช์อีกครั้ง
5. กด **"อนุญาตให้ทำงานเบื้องหลังตลอด"** (กันมือถือปิดแอปเอง) และ **"อนุญาตการแจ้งเตือน"**
   แล้วเข้า **ร้าน / Google Drive / คิวส่งไฟล์** → เลือกร้านของเครื่องนี้ (ครั้งเดียว) → เชื่อม Google ถ้าจะให้ส่ง Drive เอง (ต้องตั้ง OAuth ตาม END_TO_END.md ก่อน)
6. **เสียบสายชาร์จไว้ตลอด** · กด **"▶ เปิด Grab ที่แท็บ Ready"** → แตะแท็บ Ready → วางเครื่องทิ้งไว้ (แอปสั่งไม่ให้จอดับตลอดเวลาที่เปิด Grab ทั้งวันทั้งคืน วันถัดไปไม่ต้องมีใครมาปลุกเครื่อง — **อย่ากดปุ่มปิดจอ** ถ้าจอล็อก แอปทำงานไม่ได้จนกว่าจะปลดล็อก)
7. **ทดสอบจริง**: เมื่อมีออเดอร์เข้าแท็บ Ready → หน้าแรกของ ReadyProof ต้องขึ้น "ภาพล่าสุด: READY GF-xxx" → ดูภาพได้ใน "ภาพที่แคปไว้"

> ถ้าติดตั้งไม่ได้เลยแม้ปิด Play Protect แล้ว ดูหัวข้อ "แผนสำรองการติดตั้ง" ด้านล่าง

## อัปเดตเวอร์ชันใหม่

ดาวน์โหลดจากลิงก์เดิม → ติดตั้ง**ทับ**ได้เลย ไม่ต้องลบของเดิม (การตั้งค่า / ภาพ / สิทธิ์การช่วยเหลือพิเศษ อยู่ครบ)
ถ้าติดตั้งทับแล้ว Play Protect บล็อก ให้ปิด Play Protect ชั่วคราวแบบข้อ 1

## ใช้งานประจำวัน

ไม่ต้องทำอะไร — เปิด Grab ที่แท็บ Ready ไว้บนเครื่องนี้ตอนเปิดร้าน
- หน้าแรกของ ReadyProof บอก: มีภาพกี่ออเดอร์, รอไรเดอร์กี่ออเดอร์, กวาดรายการล่าสุดเมื่อไร, ออเดอร์ที่ยังแคปไม่ได้ (ถ้ามี)
- **จะใช้เครื่องนี้ทำอย่างอื่นนานๆ** ให้ปิดสวิตช์ "แคปอัตโนมัติ" ที่หน้าแรกก่อน ไม่งั้นแอปจะเปิด Grab กลับมาเอง

## หลังปิดร้าน (อัตโนมัติ)

1. 19:05 แอปทำเองทั้งหมด (ระหว่างนั้นอย่าแตะจอ ~1–3 นาที) — เวลาปิดร้าน/เวลาเผื่อ/รอบตรวจซ้ำ แก้ได้ในตั้งค่า
2. มีแจ้งเตือน **"สรุปสิ้นวันพร้อมแล้ว"** → แตะ → หน้ารายงาน
3. เชื่อม Drive ไว้: ชุดหลักฐาน + สรุป ส่งเข้าโฟลเดอร์ของร้านเอง · ไม่ได้เชื่อม: **ส่งหลักฐานกดทัน N ชุด** → เลือก Drive → อัปโหลด
4. **คัดลอกสรุป** → วางใน LINE · **ส่งออก CSV** → เปิดด้วย Google Sheets
- ต้องการสรุปก่อนเวลา: หน้าแรก → **"กวาด History ตอนนี้"** (ไม่ยกเลิกรอบอัตโนมัติตอนเย็น)
- ถ้าอ่านประวัติได้ไม่ครบเท่ายอด Completed แอปอ่านซ้ำเองอีกสูงสุด 2 รอบ (ทุก 5 นาที) แล้วรายงานจะบอกว่าขาดอะไร
- ถ้าเลขออเดอร์ซ้ำกันในวันเดียว (เลข GF มีแค่ 3 หลัก) แอปใส่เวลาเสร็จต่อท้ายให้ เช่น `GF-613_1147_READY.jpg`

## ปุ่มลอยสำหรับแคปเอง (ไม่บังคับ)

ตั้งค่ามือถือ → การช่วยเหลือพิเศษ → ReadyProof → เปิด **"ทางลัด ReadyProof"** → เลือก "แตะปุ่มการช่วยเหลือพิเศษ"
จะมีปุ่มเล็กลอยบนจอ แตะ = แคปทันทีพร้อมจดเลข GF ที่เห็นบนจอ

## ถ้าระบบหยุดทำงานเอง (หน้าแรกขึ้นสีเหลือง/แดง)

- ทุกยี่ห้อ: กด "อนุญาตให้ทำงานเบื้องหลังตลอด" · อย่าปัดปิด ReadyProof ทิ้งจากหน้าแอปล่าสุด
- Samsung: ตั้งค่า → แบตเตอรี่ → ขีดจำกัดการใช้งานพื้นหลัง → แอปที่ไม่เข้าสู่โหมดสลีปเลย → เพิ่ม ReadyProof
- Xiaomi/Redmi/POCO: ตั้งค่า → แอป → ReadyProof → เปิด "เริ่มอัตโนมัติ" + ตัวประหยัดแบตเตอรี่ "ไม่มีข้อจำกัด"
- OPPO/realme/vivo: ตั้งค่า → แบตเตอรี่ → ReadyProof → อนุญาตทำงานเบื้องหลัง + เริ่มอัตโนมัติ

## ถ้าแคปไม่ได้ / สรุปไม่ครบ

- ดูหน้าแรกของ ReadyProof ว่าขึ้น "● ระบบทำงานอยู่" และบรรทัดสถานะบอกอะไร (ถ้าระบบไม่ทำงาน ทำตามหัวข้อด้านบน)
- ตั้งค่า → เปิด "เก็บข้อมูลหน้าจอเพื่อแก้ปัญหา" → ปล่อยให้ทำงาน 1 วัน → "ส่งออกไฟล์ช่วยแก้ปัญหา" แล้วส่งไฟล์มาให้แก้ (ในไฟล์มีบันทึกว่าแอปกวาด/แคป/สรุปอะไรไปบ้าง) · ระหว่างนั้นใช้ปุ่มลอยแคปแทน

## ข้อจำกัดที่ควรรู้

- ออเดอร์ที่ **ไม่เคยเข้าแท็บ Ready** (เช่น ออเดอร์คู่ที่คนขับคนเดียวรับ แล้วกดเสร็จจากแท็บกำลังเตรียม) จะอยู่ในกลุ่ม "ไม่มีหลักฐาน" — รายงานบอกเลขให้ตรวจเอง
- เวลาในภาพ Ready = เวลาที่ออเดอร์เข้าแท็บ Ready (แอปแคปภายในไม่กี่วินาที) ถ้าเครื่องปิด/จอล็อกช่วงไหน ออเดอร์ช่วงนั้นจะไม่มีภาพ
- การตัดสิน "ช้าจริง" ดูจากคำในภาพแรก (ตั้งค่า → สิ้นวัน → "สถานะในภาพแรกที่แปลว่าร้านช้าจริง") ถ้าพบว่าการ์ดชมพูไม่ได้แปลว่าคนขับมาถึงแล้ว ให้ลบคำนั้นออก

## แผนสำรองการติดตั้ง (ถ้า Google บล็อกแม้ปิด Play Protect)

Google เริ่มระบบ "ยืนยันตัวตนผู้พัฒนา" ในไทยตั้งแต่ **30 ก.ย. 2026** — ตามเอกสารของ Google รอบนี้บังคับเฉพาะแอปจาก Store ที่ร่วมโครงการ ส่วนแอปที่ติดตั้งจากไฟล์โดยตรงยังไม่ถูกบังคับจนถึงรอบทั่วโลกปี 2027
ถ้าเครื่องไหนบล็อก เลือกทางใดทางหนึ่ง:

1. **Advanced flow (ทำครั้งเดียวต่อเครื่อง)**: เปิดโหมดนักพัฒนา → ตัวเลือกสำหรับนักพัฒนา → "แอปจากนักพัฒนาที่ยังไม่ยืนยัน" → เปิด → รีสตาร์ท → **รอ 24 ชม.** → ยืนยันด้วยลายนิ้วมือ/PIN → ติดตั้งได้ตามปกติ
2. **บัญชี Limited distribution (ฟรี, ไม่เกิน 20 เครื่อง, ไม่ต้องใช้บัตรประชาชน)**: ใช้บัญชี Google ที่เปิดการยืนยัน 2 ขั้นตอน + มีโปรไฟล์การชำระเงิน Google → สมัคร Android Developer Console → ลงทะเบียนแอป `io.github.panuwattegif.readyproof` พร้อม SHA-256 ของกุญแจเซ็นแอป (ใน `keystore/README.md`) → เพิ่มมือถือร้านด้วย QR code
3. **ADB จากคอมพิวเตอร์** (ไม่ต้องยืนยันใดๆ): `adb install -r ReadyProof.apk`

## ความเสี่ยงที่ควรรู้

- **บัญชี Grab**: แอปนี้อ่านหน้าจอ แคปภาพ และเลื่อน/แตะแท็บแทนคน เหมือนคนใช้เครื่องเอง ไม่แตะเซิร์ฟเวอร์ Grab — โอกาสมีปัญหาต่ำมาก แต่ไม่ใช่ศูนย์ (บางแอปตรวจเจอแอป "การช่วยเหลือพิเศษ" ได้) ถ้าวันหนึ่ง Grab แจ้งเตือนเรื่องนี้ ให้ปิดสวิตช์ ReadyProof ในหน้าการช่วยเหลือพิเศษได้ทันที
- **ภาพหลักฐาน**: เป็นภาพหน้าจอดิบ ไม่มีการแต่งเติม เวลาดูจากนาฬิกาบนแถบสถานะเหมือนภาพที่แคปเอง
- **ความจุ**: ประมาณ 15–40 MB/วัน ไม่ลบอัตโนมัติ ตรวจพื้นที่ว่างเป็นระยะ
- **จอ**: เปิดค้างตลอดขณะเปิด Grab — ตั้งความสว่างจอต่ำสุดไว้ได้ ไม่กระทบการแคป
- **ภาพสำรอง**: ออเดอร์ไหนแคปแบบตรวจเต็ม (เลข GF + สถานะ ไม่โดนอะไรบัง) ไม่ได้ภายใน 30 วินาที แอปเก็บภาพสำรองที่อย่างน้อยเลข GF อยู่ในรายการชัดๆ ไว้ก่อน แล้วพยายามแคปแบบตรวจเต็มต่อ — ไม่ปล่อยให้ออเดอร์ไหนไม่มีภาพ
- **แจ้งเตือนเมื่อมีปัญหา** (มีเสียง): ออเดอร์อยู่ในแท็บ Ready เกิน 2 นาทีแต่ยังไม่มีภาพ, แอปถูกปิด/สิทธิ์การช่วยเหลือพิเศษหลุด (ตรวจทุก 15 นาที), พากลับแท็บ Ready ไม่ได้

## สำหรับผู้พัฒนา

```
readyproof/
  core/   Kotlin ล้วน ไม่พึ่ง Android (มี unit test)
          ScreenAnalyzer  อ่านการ์ดออเดอร์ + เช็กว่าเลข GF/สถานะ "อยู่ในจอเต็มๆ ไม่โดนบัง" (CardView.full)
          Tabs / History  แท็บที่เปิดอยู่, จุดแตะแท็บอย่างปลอดภัย, หัวหน้าประวัติ (วันที่, Completed, Cancelled)
          ReadyTracker    ออเดอร์ไหนอยู่ในแท็บ Ready และมีภาพแล้วหรือยัง (ภาพละครั้งต่อการเข้าแท็บ)
          Report          จับคู่ DELAY กับภาพ READY → กดทัน / ช้าจริง / ไม่มีหลักฐาน, % แบบ Grab และ % จริง
  app/    Android: ProofService (accessibility) → Engine (เฝ้า/กวาด/พากลับ/สิ้นวัน),
          ScreenReader, Actor (เลื่อน/แตะแท็บ), CaptureManager (แคปเงียบ + ตรวจซ้ำหลังแคป), Notifier,
          DailyExport (สรุป + manifest), DriveSync/DriveWorker (ส่ง Drive หลังปิดร้าน), หน้าจอ ui/*
  ../readyproof-pc/   รุ่น PC (แยกต่างหาก)
```

- ทุกพฤติกรรมอยู่ใน `core/.../Config.kt` (ชื่อแท็บ, คำหน้า History ไทย/อังกฤษ, เวลาปิดร้าน, รอบตรวจ, คำที่แปลว่าช้าจริง, รูปแบบเลข GF) แก้ได้จากหน้าตั้งค่าในแอป
- โค้ดอ่านหน้าจอทดสอบกับโครงหน้าจอจริงของ GrabMerchant ทั้งไทยและอังกฤษใน `core/src/test/.../Trees.kt` (+ `Layout.kt` จำลองตำแหน่งบนจอ, การ์ดโดนตัดขอบ/โดนบัง)
